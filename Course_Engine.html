One file, every class. Pick a section from the Class menu. The roll sheet, the teams, and the roster all follow that one choice. Each class carries its own accent color and its own AM or PM tag, so on days you teach two sections there is no way to mark the wrong sheet.
Two sheets per class. The Class list holds everyone currently in the section, enrolled or waitlisted. Waitlisted students are marked W; the W disappears the moment you enroll them, and the promotion is dated in their history. The Dropped / No-show sheet holds everyone who left, filterable to drops only or no-shows only.
One pull-down moves people. On Roster & Status, change a student's Status menu. Wait list to Enrolled happens right away. Dropped and No-show open a short dialog so the effective date and reason are recorded, and every change stays in that student's history.
Marking attendance. Click a cell to cycle: ✓ present, – partial, ✕ absent, then blank. Use the dash when a student was there for part of the session. If you want to record which part they missed, turn on Separate lecture and lab attendance in Class setup and each day gets its own Lec and Lab mark.
Teams (TBL): set how many teams a class uses in Class setup, rename them in the team bar, then pick each student's team from the pull-down on their row. Team colors are fixed and contrast-checked.
Backup all downloads every class as one file. Storage is per browser and per web address, so back up before clearing browser data or moving to another computer.

This is an attendance sheet, not a gradebook. No scores, points, or grades are stored here. Grades stay in Canvas. What this file keeps is a roster, attendance marks, team assignments, and dated enrollment status changes, and it keeps all of it in this browser only. Nothing is sent to a server. Students flagged [C] are marked FERPA confidential / directory hold. Treat exported CSV files as student records: they belong on college-managed storage, not in personal cloud folders or email.

Class identity
Meeting schedule

List any holidays or campus closures under No-class dates, separated by commas, and no attendance column is generated for them. Set AM, PM, or EVE when you teach two sections on the same weekdays. It shows on every day column, in the class menu, in the header, and on your exports, so the two roll sheets can never be confused. An online class with no meeting days is fine: leave the days unchecked and the roster still works.

Teams

Turn on Separate lecture and lab attendance when a class meets for both in one day and students can attend one without the other. Each class day then gets two marks, Lec and Lab, so a partial day is recorded accurately instead of being forced to all-present or all-absent. Each class keeps its own team names, and the team pull-down on a student's row lists only the number of teams you set here. Beside Team is a Pos pull-down for the student's position within that team; set how many positions a team has above, usually the same as the number of members. If two students on one team land on the same position, the Pos cell is flagged so you can catch it. The switch can be toggled any time from the toolbar.
